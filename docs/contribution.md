# 기여 범위

## 직접 담당한 것으로 확인된 범위

- 네트워크 연결 UI와 Host/Client 시작
- 네트워크 오브젝트 등록과 생성 요청
- 플레이어 생성 위치 및 XR Origin 처리
- 플레이어 Transform 동기화 방식 설정
- PC 관제와 VR 플레이어 뷰 연결
- 미니맵 상호작용의 네트워크 연동
- 실시간 음성 채팅 서비스 연동

## 프로젝트 전체 기능과의 구분

재난 콘텐츠, 환경 제작, 모든 상호작용과 전체 UI를 네트워크 담당자의 단독 구현으로 주장하지 않습니다. 포트폴리오에는 역할 문서와 코드가 함께 확인되는 범위만 기여 항목으로 사용합니다.
