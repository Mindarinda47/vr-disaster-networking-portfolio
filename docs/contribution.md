# 기여 범위

## 문서로 확인된 역할

최종보고서의 역할 분담과 네트워크 구현 장을 현재 코드와 대조했습니다. 개인정보와 팀원 정보는 저장소에 옮기지 않았습니다.

| 보고서에 구분된 담당 영역 | 코드·구현 근거 |
| --- | --- |
| 기기 간 네트워크 연결 및 설정 | `NetworkConnect`, `NetworkObjectManager`, Netcode Host/Client와 플레이어 소유권 설정 |
| 1:1 의사소통 기법 | 미니맵 마커·화재 배치, 참가자 시점 모니터링, 층 이동 |
| UI 디자인 및 최적화 | PC 관제 화면 전환, 마커·화재·제거·층 이동 입력 흐름 |
| Vivox 음성 채팅 연동 | Vivox 패키지·제공 UI/샘플 활용, 입출력 장치·음량 설정, 직접 작성한 마이크 버튼 상태 UI |

## 직접 담당한 범위

### 핵심 구현

- Host/Client 시작과 연결 완료 대기
- 접속 Client용 VR 플레이어의 서버 생성·등록·소유권 이전
- HMD·양손 Transform 반영과 Client-authoritative 동기화 설정
- ServerRpc/ClientRpc를 이용한 위치 이동과 Client별 화면 상태 전환
- PC 미니맵 좌표의 월드 좌표 변환
- 서버 권한 마커·화재 생성/삭제와 최대 생성 수 관리
- 관제 카메라의 VR 플레이어 시점 연결

### 관제 상호작용의 목적

- 마커를 한 개만 유지해 참가자에게 현재 이동 목표를 명확하게 전달
- 화재를 추가·제거해 세션 중 난이도와 이동 경로를 동적으로 변경
- 참가자 머리 Transform을 따라가는 관제 카메라로 행동을 실시간 확인
- 참가자가 잘못된 행동을 하거나 길을 잃었을 때 마커와 음성으로 즉시 피드백

### 서비스·UI 연동

- PC 관제 화면과 VR 화면의 UI 흐름 연결
- Vivox SDK와 제공 샘플을 활용한 음성 채팅 서비스 연동
- 음성 채팅 마이크 버튼의 UI 상태 제어

## 기여 범위 밖의 항목

재난 환경과 에셋 제작, 전체 콘텐츠와 모든 상호작용, Vivox SDK 내부 구현, 팀원의 기능은 단독 기여로 주장하지 않습니다. 이 저장소에는 역할 설명과 실제 코드가 함께 확인되는 네트워크·관제 연동 범위만 담았습니다.
