## 포트폴리오 코드 정리 범위

원본 팀 저장소는 수정하지 않았습니다. 이 선별본에서만 다음과 같은 동작 비변경 정리를 적용했습니다.

- Windows 한글 인코딩으로 저장돼 깨져 보이던 주석을 UTF-8로 변환
- 실행되지 않는 이전 시도와 마이크 직접 제어 주석 코드 제거
- 반복 출력되는 개발 확인용 로그와 명백히 사용하지 않는 `using`·상태 제거
- 런타임 경고·오류 로그, RPC·소유권·생성·동기화 로직은 유지

## 공개 범위

- 담당 코드 검토에 필요한 C# 스크립트와 설명 문서만 공개합니다.
- 팀원 코드, 개인정보, 강의·과제 자료, 제3자 에셋, Vivox 샘플 코드와 서비스 설정은 제외했습니다.
- 빌드 파일과 Unity 캐시를 제외해 심사위원이 담당 코드에 바로 접근할 수 있도록 구성했습니다.

## 해석 시 유의사항

- 이 저장소만으로 전체 Unity 프로젝트를 실행할 수는 없습니다.
- 시연 영상은 프로젝트 전체 결과이며, 모든 기능을 개인 기여로 주장하지 않습니다.
- Vivox는 SDK와 제공 샘플 기반의 서비스 연동 경험입니다. 음성 코덱이나 전송 프로토콜을 직접 구현한 사례가 아닙니다.
- 최종보고서는 일부 상호작용과 최적화의 한계를 기록하고 있습니다. 이 선별본은 전체 시스템의 상용 완성도를 주장하지 않고, 문서와 코드로 확인되는 네트워크·관제 구현 범위만 제시합니다.
